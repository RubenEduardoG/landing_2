# BOSCO - Instalación

Abrir esta carpeta `project` en VS Code (la que contiene `package.json`).

```bash
npm install
npm run dev
```

Abrir la URL local indicada por Vite. Para verificar producción: `npm run build`.

Los medios originales no están incluidos; agregarlos luego en `public/assets/` manteniendo los nombres usados en `src/content.js` y `src/templates.js`. Las integraciones GHL/WhatsApp/Meta aún están pendientes y no deben considerarse funcionales.
