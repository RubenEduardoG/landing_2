# BOSCO — Landing integrada

Proyecto Vite con el código corregido por Claude y los recursos originales integrados.

## Ejecutar
1. Abrir ESTA carpeta en VS Code (donde está `package.json`).
2. `npm install`
3. `npm run dev`
4. `npm run build` para verificar la compilación.

## Recursos
- `public/assets/videos/vsl.mp4`: video principal.
- `public/assets/videos/`: testimonios originales.
- `public/assets/imagenes/marisol.webp`: nueva fotografía enviada.
- `public/assets/imagenes/tabla-plusvalia-bosco.webp`: captura del cliente recortada, sin bordes negros.
- Otros recursos originales en `public/assets/imagenes/`.

## Pendiente antes de publicar
- Configurar y probar GHL (formulario, agenda y pipeline), WhatsApp, Meta y aviso de privacidad.
- Confirmar responsable de la campaña y citas.
- Validar cifras financieras y permisos de testimonios para publicidad.
- La tabla es una imagen del cliente con cifras ilustrativas, no una garantía de rendimientos.
